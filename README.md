# Built with Claude

Every tool from my reels, in one place. I'm Julien Design Craft (@juliendesigncraft): I design, and Claude writes the code with me.

Nothing here is a finished app you download. It's what you need to build your own with Claude Code: the prompts I used, the reference images, and the guides Claude follows. You end up with the code, on your computer, and you can change anything.

## How to use it with Claude Code

1. Download this repo (green **Code** button, **Download ZIP**) or `git clone` it.
2. Open the folder of the tool you want.
3. For a prompt: copy it into Claude Code and attach the images from the same folder.
4. For Spazio Starter: open the folder in Claude Code and paste `Read CLAUDE.md and build my Spazio with me, one phase at a time.`

Claude shows you a plan first and waits for your OK. Build one step at a time and try each one before the next.

You need [Claude Code](https://claude.com/claude-code). The Mac apps need a Mac. Spazio works on Mac and Windows.
